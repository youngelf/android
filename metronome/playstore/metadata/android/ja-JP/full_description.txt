『Metronome — 高精度振り子メトロノーム＆スピードコーチ』で、揺るぎないタイム感、複雑な変拍子やポリリズム、そして確実なスピードアップを身につけましょう。ギタリスト、ドラマー、ピアニスト、吹奏楽・アンサンブル奏者のために設計され、44.1 kHz サンプル精度のPCM音声合成エンジンによりモバイル機器特有のタイミングの揺らぎ（ジッター）を完全に排除しています。

44.1 kHz サンプル精度のタイミング＆視覚的な振り子アニメーション
• ゼロジッター・オーディオエンジン：すべてのクリック、アクセント、サブディビジョンを 44.1 kHz の1サンプル単位で正確に計算。
• 譜面台からでも見やすいハイコントラストな振り子アニメーションとビートLEDマトリクス。
• タップテンポおよび -5 / -1 / +1 / +5 BPM の微調整（20〜260 BPM）、イタリア語速度標語（Largo〜Presto）を表示。

12種類の拍子記号（変拍子対応）＆ 6種類のサブディビジョン
• 4/4, 3/4, 2/4, 6/8, 9/8, 12/8 に加え、5/4, 5/8, 7/4, 7/8, 11/8, 13/8 などの変拍子に対応。
• 拍ごとのアクセントシーケンサー：各拍をタップして強アクセント、通常拍、中アクセント、ミュートを自在に設定。
• 4分音符、8分音符、3連符、16分音符、付点8分（スウィング）、5連符の6種類の分割に対応。

ポリリズム生成、スピードトレーナー＆ミュート小節（バードロッパー）
• 3:2、4:3、5:3、5:4、7:4 などのポリリズムを視覚と音で同時に確認。
• N小節ごとに自動でテンポを引き上げるスピードコーチと、数小節おきにクリックを消して体内時計を鍛えるミュート小節モードを搭載。
• 5種類のクリック音色、練習中の画面スリープ防止、縦・横画面対応、100%オフライン・広告なし。
